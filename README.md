# Hello Plant World

A simple static website published with GitHub Pages.

Website: https://helloplantworld.github.io/

To publish at this address, the GitHub repository must be named `helloplantworld.github.io`. Enable GitHub Pages from `main` and `/ (root)` in the repository's Pages settings.

Edit `index.html` and push to `main` to update the website. GitHub Pages serves the repository root. The `.nojekyll` file disables Jekyll processing.
